# CogniTrack: Feature Breakdown

## 1. Gamified Assessment Modules
CogniTrack includes 4 interactive modules, each targeting a specific executive function.

### A. Go / No-Go Test
- **Domain**: Sustained Attention & Impulse Control.
- **Mechanic**: User must quickly press Spacebar when a Green Sphere appears, but suppress the urge to click when a Red Diamond appears.
- **Metrics**: Reaction time, Omission Errors (missed targets), Commission Errors (impulsive clicks).

### B. Memory Span (Corsi Block-Tapping)
- **Domain**: Visuospatial Working Memory.
- **Mechanic**: A 3x3 grid flashes a sequence. The user must replicate the sequence. The sequence length increases by 1 each successful round.
- **Metrics**: Maximum sequence length (Max Span) successfully recalled.

### C. Shape Shifter (DCCS)
- **Domain**: Cognitive Flexibility.
- **Mechanic**: User sorts cards into bins. Halfway through the test, the sorting rule changes (e.g., sort by Color, then suddenly sort by Shape).
- **Metrics**: Post-switch accuracy rate, reaction latency.

### D. Connect the Stars (Trail Making Test - Part B)
- **Domain**: Processing Speed & Visual Search.
- **Mechanic**: User must click scattered stars in an alternating alphanumeric sequence (1 -> A -> 2 -> B). Draws a dynamic SVG line between correct clicks.
- **Metrics**: Total completion time, sequence error count.

## 2. Clinical Context Integration
- **Feature**: A glassmorphic Info button on every game's start screen.
- **Functionality**: Triggers `ClinicalInfoModal.jsx`, explaining the psychological foundation of the game and providing a direct link to NIH/PubMed medical literature, establishing immediate credibility.

## 3. Clinical Dashboard
- **Radar Chart**: A dynamic, 5-point polygon built with Recharts (`recharts`) that maps the string-based ML classifications back to a 100-point visual scale.
- **Top-Level Metrics**: A clean, widget-based breakdown of exactly how the patient scored in each specific domain.
- **AI Prescriptions**: A list of actionable, clinical recommendations generated by the backend ML service based on the specific metrics gathered during the sessions.

## 4. Modern UI/UX Architecture
- **Responsive Grid**: A dynamic CSS grid layout (`lg:grid-cols-3`) that seamlessly organizes the expanding library of modules.
- **Aesthetics**: Premium visual design utilizing Tailwind CSS backdrop blurs, extensive custom gradients, and CSS keyframe animations to prevent the application from feeling like sterile medical software.
